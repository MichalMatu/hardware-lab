# Documentation

This directory is a starting point for short design notes and experimental findings. No detailed specification has been approved yet.

## Topics to explore

- Realistic ESP32-S3 use cases: signal analysis, anomaly detection, prediction, and other small on-device tasks.
- Memory constraints, especially internal DRAM versus PSRAM and safe allocation patterns.
- Available sensor samples and representative datasets.
- Algorithm choices: statistical methods, compact inference, or combinations.
- Modularity, offline testing, hardware verification and possible future adapters to other projects.

## Decision status

All topics above are **unresolved**. Record actual measurements and decisions as they happen; avoid promising capabilities or performance before testing.

This directory does not define an implementation roadmap or authorize changes to GrowClip.
